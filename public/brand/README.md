# Fayda MCP logo: "Relay F"

An F whose short arm hands off to a detached dot: the request goes out, one bit comes back.
Independent open-source project; not official Fayda / National ID Program branding.

## Files
| File | Use |
|---|---|
| `logo-horizontal-light.svg` / `-dark.svg` (+ `.png`) | Primary lockup on light / dark backgrounds |
| `logo-stacked-light.svg` / `-dark.svg` | Square-ish spaces (social, slides) |
| `symbol-light.svg` / `symbol-dark.svg` | Symbol alone |
| `icon-tile.svg` | Brand chip / app icon (ink tile, paper F, butter dot) |
| `icon-tile-small.svg` | Small-size cut for 16–32 px (heavier strokes, wider gap); used as `src/app/icon.svg` and `favicon.ico` |
| `wordmark-light.svg` | Wordmark alone |

## Colour
| Name | HEX | Role |
|---|---|---|
| Ink | `#183d32` | Mark, wordmark, tile |
| Paper | `#f7f9f5` | Mark on dark |
| Butter | `#ffe46b` | Accent: the dot only, on dark/ink backgrounds |

On light backgrounds the dot is ink (butter on white fails contrast).

## Type
Wordmark: DM Sans (OFL), weight 650, optical size 40, tracking −0.03 em, converted to outlines.

## Rules
- Clear space: the dot's diameter on every side.
- Minimum size: symbol 16 px (use the small cut below 32 px); horizontal lockup 96 px wide.
- Don't recolour the F butter, add gradients/shadows, rotate, move the dot, or re-set the wordmark in another font.
